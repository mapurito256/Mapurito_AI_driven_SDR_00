# Local snapshot - FM band use reference (illustrative)

> Illustrative local snapshot for the seed case. It stands in for the
> authoritative spectrum-use reference the real corpus would hold. It is not a
> real legal instrument and is here only to exercise the source mechanism.

The FM broadcast band spans 88 to 108 MHz and is allocated to broadcasting.
Use of the band is subject to the national spectrum authority's rules.
Receiving and monitoring occupancy in the band does not transmit any signal.
